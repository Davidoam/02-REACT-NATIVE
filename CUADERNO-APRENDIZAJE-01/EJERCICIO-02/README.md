# Ejercicio 02 - Tarjeta de bienvenida

## Qué he aprendido
He aprendido el Box Model de React Native mediante una tarjeta.

## Respuesta a la pregunta de comprensión
¿Por qué usarías `padding` en una tarjeta en lugar de `margin` para separar el texto del borde?

Respuesta:
El padding separa el contenido del borde interior. El margin separa un elemento de lo que tiene alrededor. borderRadius redondea las esquinas.
