# Ejercicio 01 - Mi primera pantalla

## Qué he aprendido
He aprendido a crear una pantalla mínima de una app para comprobar que entriendo la estructura View → Text → StyleSheet.

## Respuesta a la pregunta de comprensión
Explica con tus palabras la diferencia entre el componente `View` y el componente `Text`.

Respuesta:
View es un contenedor visual. Text muestra texto. Los estilos no se escriben como CSS tradicional: se definen como objetos JavaScript dentro de StyleSheet.create().

## Qué he modificado
He usado un componente Text extra y le he creado un estilo propio. Además, le he dado un poco de gap al contenedor para que haya más espacio entre los text.

## Resultado
Explica brevemente cómo ha quedado la interfaz.
La interfaz ha quedado centrada y alineada en el centro. Con tres textos con sus diferentes estilos.
