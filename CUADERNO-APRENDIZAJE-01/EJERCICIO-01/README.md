# Ejercicio 01 - Mi primera pantalla

## Qué he aprendido

He aprendido a construir una pantalla básica con `View` y `Text`, a definir sus estilos mediante `StyleSheet` y a centrar el contenido con Flexbox.

## Respuesta a la pregunta de comprensión

Explica con tus palabras la diferencia entre el componente `View` y el componente `Text`.

Respuesta:

`View` es un contenedor que permite agrupar, distribuir y aplicar estilos a otros componentes. `Text` se utiliza para mostrar contenido textual y también puede recibir estilos propios.

## Qué he modificado

- He añadido una tercera línea con el texto «Curso 2026/27».
- He creado un estilo específico para esa línea.
- He añadido separación entre los textos sin alterar su centrado.

## Resultado

La interfaz muestra tres textos centrados vertical y horizontalmente, con una jerarquía visual diferente para el título, el subtítulo y el curso.
