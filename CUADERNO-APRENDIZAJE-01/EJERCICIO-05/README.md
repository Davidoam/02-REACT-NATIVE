# Ejercicio 05 - Tarjeta de producto

## Qué he aprendido

He aprendido a combinar imágenes, jerarquía tipográfica y distribución horizontal dentro de una tarjeta de producto.

## Respuesta a la pregunta de comprensión

¿Qué información debería tener mayor jerarquía visual: categoría, nombre del producto o precio? Justifica tu decisión.

Respuesta:

El nombre del producto y el precio deberían tener la mayor jerarquía. El nombre permite identificar rápidamente el artículo y el precio aporta la información principal para decidir una compra. La categoría puede mostrarse con un tamaño menor porque funciona como información complementaria.

## Qué he modificado

- He sustituido el producto original por una guitarra Epiphone Les Paul.
- He personalizado la imagen, la categoría, la valoración y el precio.
- He añadido una etiqueta «OFERTA» antes del nombre del producto.

## Resultado

La interfaz muestra una tarjeta de producto personalizada, con la imagen recortada por los bordes redondeados, una etiqueta de oferta y una fila final que separa el precio del botón de compra.
